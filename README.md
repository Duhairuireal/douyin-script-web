# 视频成稿

把公开的抖音视频、抖音图文与 B站视频转换为完整文字稿，再用 AI 生成成稿。

## 当前能力

- TikHub 解析抖音分享链接与视频地址
- 自动识别抖音视频与图文：视频走 ASR，图文读取图片文字
- 读取 B站 UP 主主页，分页展示作品标题并批量选择
- B站优先使用公开字幕；无字幕时才调用豆包 ASR，降低成本
- 抖音单条、手动导入和 B站批量结果统一进入历史文稿库
- 历史记录保留不可覆盖的原始转写，并提供可手动编辑、可用新提示词继续 AI 改写的工作稿
- 支持账号 + 密码的本机内测登录；同一浏览器中的不同测试账号分别保存 API Key 与历史文稿
- 内测账号的密码只保存摘要，不保存明文；首次注册会接收当前浏览器里以前填写过的连接设置
- 原有 ChatGPT 登录入口暂时保留，用于读取以前按账号同步的 API Key 与云端历史文稿
- 火山豆包录音文件识别 2.0 生成文字稿
- OpenRouter 免费模型路由作为默认总结模型
- DeepSeek V4 Flash / V4 Pro 总结
- 自定义 OpenAI 兼容 API 地址、API Key、模型 ID 与显示名称
- 可填写生成提示词，把文字稿整理成公众号文章、小红书笔记或其他指定形式
- 支持直接粘贴已有文字稿，跳过视频解析和语音识别
- 下载 TXT 或 Markdown，接口错误会显示服务名、状态码和原始原因

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

正式构建检查：

```bash
npm run build
```

## 密钥说明

内测账号的 API Key 与历史文稿只保存在当前浏览器，并按测试账号隔离；清理浏览器数据或换设备后无法恢复。使用旧版 ChatGPT 登录时，API Key 仍使用 AES-GCM 加密后保存到账号数据库。密钥仅在发起请求时临时交给本站 API 路由转发，不会写入项目源码。不要把真实密钥提交到 Git 仓库。

公开商用前，应按 [PROJECT_NOTES.md](./PROJECT_NOTES.md) 把内测账号迁移到 Supabase Auth，并把 TikHub 与火山 ASR 密钥迁移为服务器端环境变量，加入用户账号、额度、计费和防滥用控制。
