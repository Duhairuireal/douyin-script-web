# 抖音成稿

把公开的抖音视频链接转换为完整文字稿，再用 AI 生成结构化中文摘要。

## 当前能力

- TikHub 解析抖音分享链接与视频地址
- 火山豆包录音文件识别 2.0 生成文字稿
- OpenRouter 免费模型路由作为默认总结模型
- DeepSeek V4 Flash / V4 Pro 总结
- 自定义 OpenAI 兼容 API 地址、API Key、模型 ID 与显示名称
- 支持直接粘贴已有文字稿，跳过视频解析和语音识别
- 下载 TXT 或 Markdown，接口错误会显示服务名、状态码和原始原因

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

正式构建检查：

```bash
npm run build
```

## 密钥说明

测试版的 API Key 保存在当前浏览器的本地存储中，并在发起请求时临时交给本站 API 路由转发，不会写入项目源码。不要把真实密钥提交到 Git 仓库。

公开商用前，应把 TikHub 与火山 ASR 密钥迁移为服务器端环境变量，并加入用户账号、额度、计费和防滥用控制。
